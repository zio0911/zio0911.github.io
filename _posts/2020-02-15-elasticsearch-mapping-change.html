안녕하세요 지오입니다.

금일은 엘라스틱 서치 중단 없이 맵핑 정보를 변경하는 방법에 대해서 서술하려고 합니다.


엘라스틱 서치 맵핑을 변경 하는 명령어를 입력시

"resource_already_exists_exception"

오류가 발생하게 되는데요.


이미 기존의 데이터가 있는 상태에서 맵핑 정보를 변경 할 수 없기 때문입니다.

데이터를 변경하기 위해서는 변경하려는 맵핑정보로 신규 인덱스를 생성후 이름을 변경해주면 됩니다.


1. 기존 인덱스 (keyword 타입)

curl -XPUT 'host:9200/ip_master?pretty' -H 'Content-Type: application/json' -d'
{
  "mappings": {
    "view": {
      "_all": { "enabled": false },
      "properties": {
        "ip_addr": { "type": "keyword" },
        "seq_no":  { "type": "long" }
      }
    }
  }
}'


키워드로 생성된 정보가 있다고 한다면

해당 ip_addr에 대한 타입을 ip로 변경하려고 한다면


2. 변경된 타입으로 신규 인덱스 생성

curl -XPUT 'host:9200/ip_master2?pretty' -H 'Content-Type: application/json' -d'
{
  "mappings": {
    "view": {
      "_all": { "enabled": false },
      "properties": {
        "ip_addr": { "type": "ip" },
        "seq_no":  { "type": "long" }
      }
    }
  }
}'


위와 같이 변경된 타입에 대한 인덱스를 생성후에


3. Reindex로 데이터 이전

curl -X POST "host:9200/_reindex" -H 'Content-Type: application/json' -d'
{
  "source": {
    "index": "ip_master"
  },
  "dest": {
    "index": "ip_master2"
  }
}'


reindex로 변경을 하면 데이터가 변경되어 입력됩니다.

변경된 후에 기존의 인덱스를 삭제 후에 다시 변경해주면 중단없이 타입을 변경 할 수 있습니다.

Hello, this is Zio.

Today I'm going to explain how to change mapping information in ElasticSearch without any downtime.


When you try to change an ElasticSearch mapping, you'll encounter the following error:

"resource_already_exists_exception"


This is because you cannot modify the mapping of an index that already contains data.

To change the mapping, you need to create a new index with the desired mapping and then migrate the data.


1. Original Index (keyword type)

curl -XPUT 'host:9200/ip_master?pretty' -H 'Content-Type: application/json' -d'
{
  "mappings": {
    "view": {
      "_all": { "enabled": false },
      "properties": {
        "ip_addr": { "type": "keyword" },
        "seq_no":  { "type": "long" }
      }
    }
  }
}'


Assuming you have data created with the keyword type,

and you want to change the type of ip_addr to ip:


2. Create a New Index with the Updated Type

curl -XPUT 'host:9200/ip_master2?pretty' -H 'Content-Type: application/json' -d'
{
  "mappings": {
    "view": {
      "_all": { "enabled": false },
      "properties": {
        "ip_addr": { "type": "ip" },
        "seq_no":  { "type": "long" }
      }
    }
  }
}'


After creating the new index with the updated type:


3. Migrate Data with Reindex

curl -X POST "host:9200/_reindex" -H 'Content-Type: application/json' -d'
{
  "source": {
    "index": "ip_master"
  },
  "dest": {
    "index": "ip_master2"
  }
}'


By using reindex, the data will be migrated with the new mapping applied.

After the migration, delete the original index and recreate it with the new mapping, allowing you to change the type without any downtime.
